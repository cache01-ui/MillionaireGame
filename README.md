# Гра «Хто хоче стати мільйонером» (C# Console)

Проста консольна гра-вікторина за мотивами телешоу «Хто хоче стати мільйонером?», написана на C# (.NET).

## Опис проєкту

Програма пропонує користувачеві відповісти на 5 запитань на загальну ерудицію. До кожного запитання надається 4 варіанти відповіді.
* За кожну правильну відповідь нараховується **100 балів**.
* Якщо відповідь неправильна — гра негайно завершується.
* Мета — дати послідовні правильні відповіді на всі запитання та набрати максимум (500 балів).
